## Setup

Requires [Ollama](https://ollama.com/download) and [uv](https://docs.astral.sh/uv/).

```bash
git clone https://github.com/milindnevrekar-beep/genai_course_term4.git
cd genai_course_term4
ollama pull llama3.2
uv sync
uv run jupyter notebook
```

Open the notebooks from the `Assignment 1` folder and run all cells.
